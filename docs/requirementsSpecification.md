# 機能要件定義書
**プロジェクト名:** コトバのゆりかご

**作成日:** 2025年10月31日

## 1. 概要
本プロジェクトは、借用語や新語に対する新しい日本語訳を考案し、議論し、共有するための共創型Webプラットフォーム「コトバのゆりかご」を開発するものである。

## 2. 目的と背景
* **課題:** 既存の訳語にしっくりこない、あるいは、借用語をそのまま使用することに違和感を覚えるといった、言葉に関心を持つ人々の知的な課題に応える。
* **目的:** ユーザーが主体的に「新しい訳語を創造するプロセス」そのものに参加し、議論を通じて言葉への理解を深める場を提供する。

## 3. 対象ユーザー
* 言葉（特に新語・借用語・外来語）に敏感な人。
* 翻訳家、ライター、編集者、学生、研究者。
* 「しっくりくる日本語」の探求に興味があるすべての人。

## 4. スコープ (MVPの定義)
本プロジェクトでは、迅速なリリースとユーザーフィードバックの獲得を目的とし、以下の機能を「MVP (Minimum Viable Product)」として定義する。

### 4.1. MVPに含まれる機能
* **ユーザー認証機能:** 新規登録、ログイン、ログアウト。
* **お題 (Subject) 管理機能:** お題の登録、一覧表示、詳細表示。
* **訳語案 (Proposal) 管理機能:** 訳語案の投稿、一覧表示、編集、削除。
* **評価 (Vote) 機能:** 訳語案に対する「支持」機能。
* **議論フォーラム機能:**
    * 議論トピック (スレッド) の作成、閲覧、編集、削除。
    * コメントの投稿、閲覧、編集、削除（返信含む）。

### 4.2. MVPに含まれない機能 (Phase 2以降)
* Wikiエンジン（議論の蓄積・まとめ機能）
* 生成AIによる補助機能（アイデア出し支援、例文作成、議論要約など）

## 5. 機能要件

### 5.1. ユーザー認証 (`Devise`)
* ユーザーはメールアドレスとパスワードで新規登録できる。
* 登録済みユーザーはログイン・ログアウトできる。

### 5.2. お題 (Subject)
* ログインユーザーは、新しい「お題」（例: "Sustainability"）とその説明文を登録できる。
* すべてのユーザーはお題を一覧・詳細閲覧できる。

### 5.3. 訳語案 (Proposal)
* ログインユーザーは、特定のお題に対して「訳語案」（例: "未来継承"）と「提案理由」を投稿できる。
* 投稿者本人のみ、自分の訳語案を編集・削除できる (`Pundit`による認可)。

### 5.4. 評価 (Vote)
* ログインユーザーは、各訳語案に対して1回「支持 (Vote)」できる。
* 再度押下することで支持を取り消すことができる。
* 各訳語案の支持数が表示される。

### 5.5. 議論フォーラム (Discussion / Comment)
* ログインユーザーは、議論トピック（スレッド）を作成できる。
    * トピックは「お題全体」または「特定の訳語案」のいずれかに紐づける（ポリモーフィック関連）。
* ログインユーザーは、トピックに対してコメントを投稿できる。
* コメントは、他のコメントへの返信（入れ子構造）をサポートする。
* 投稿者本人のみ、自分のトピックやコメントを編集・削除できる (`Pundit`による認可)。

## 6. 非機能要件

### 6.1. プラットフォーム
* PC（デスクトップ）のWebブラウザを主要な閲覧・操作環境とする。

### 6.2. UI/UX
* **Hotwire (Turbo + Stimulus)** を採用し、ページ全体の再読み込みを最小限に抑え、SPA（シングルページアプリケーション）に類する高速な操作感を実現する。
* 画面レイアウトは、PCの横幅を活かしたマルチカラム（多段組み）設計を基本とする（ワイヤーフレーム参照）。

### 6.3. デザイン
* **Tailwind CSS** を採用し、ユーティリティファーストのアプローチで、クリーンでメンテナンス性の高いデザインを構築する。

### 6.4. 認可 (Authorization)
* **Pundit** を採用し、リソース（訳語案、トピック等）の操作権限（編集・削除）が、投稿者本人のみに限定されることを保証する。

## 7. データベース設計 (スキーマ概要)
MVPの機能を実現するため、以下の6つの主要テーブルを定義する。

1.  **`users`**: ユーザー情報（email, password, username 等）
2.  **`subjects`**: お題（title, description, user_id）
3.  **`proposals`**: 訳語案（term, reasoning, subject_id, user_id）
4.  **`votes`**: 評価（user_id, proposal_id）
5.  **`discussion_topics`**: 議論トピック（title, body, user_id, discussable_type, discussable_id）
6.  **`comments`**: コメント（body, discussion_topic_id, user_id, parent_comment_id）

## 8. 技術スタックとインフラ

| カテゴリ | 採用技術 | 目的 |
| :--- | :--- | :--- |
| **バックエンド** | Ruby on Rails (7.x) | アプリケーションのコアロジック |
| **フロントエンド** | Hotwire (Turbo + Stimulus) | SPAライクなUIの実現 |
| **データベース** | PostgreSQL | データ永続化 |
| **CSS** | Tailwind CSS | UIデザインの構築 |
| **認証** | Devise (Gem) | ユーザー認証機能の実装 |
| **認可** | Pundit (Gem) | 操作権限の管理 |
| **デプロイ先** | Render.com | MVPの迅速な公開 (※さくらのVPSも将来的な候補) |
