# ワイヤーフレーム

## モバイル版アプリのワイヤーフレーム案


### 1\. ホーム画面

**目的:** ユーザーが「今どんな言葉が議論されているか」を把握し、興味のある「お題」を見つけるための画面です。

```
+-------------------------------------------+
| [アプリロゴ]       [検索🔍] [👤アイコン] |
+===========================================+
|                                           |
|  [ タブ: 議論が活発 | 新着のお題 ]        |
|                                           |
+-------------------------------------------+
|                                           |
|  [ お題カード ]                           |
|  お題: "Sustainability"                   |
|  代表訳語: 持続可能性                       |
|  [議論 58件] [訳語案 12件]                |
|                                           |
+-------------------------------------------+
|                                           |
|  [ お題カード ]                           |
|  お題: "Metaverse"                        |
|  代表訳語: (まだありません)                 |
|  [議論 120件] [訳語案 45件]               |
|                                           |
+-------------------------------------------+
|  [ お題カード ] ... (以下スクロール)      |
|                                           |
|                                           |
|                                     [+]   | <-- 新しいお題の提案
+-------------------------------------------+
| [ホーム] [見つける] [通知] [マイページ]     |
+-------------------------------------------+
```

  * **ヘッダー:** 検索機能と、ユーザー情報（プロフィールや設定）への導線を配置します。
  * **タブ:** ユーザーが「今盛り上がっている議論」と「新しく始まった議論」を切り替えられるようにします。
  * **お題カード:** 各「お題」の概要をカード形式で表示し、タップすると「2. お題詳細ページ」に移動します。
  * **フローティングボタン (+):** ユーザーが新しい「お題」を提案するためのボタンです。

-----

### 2\. お題詳細ページ

**目的:** アプリの核となる画面です。ここで「訳語案の閲覧」「議論」「Wikiの確認」を行います。

```
+-------------------------------------------+
| [←戻る]  Sustainability  [☆ブックマーク] |
+===========================================+
|                                           |
|  [原語の意味・背景説明エリア]               |
|  "sustain (持続する) と ability (能力)..."|
|                                           |
+-------------------------------------------+
|                                           |
|  [ 訳語案一覧 | 議論フォーラム | Wikiまとめ ]  <-- タブ
|                                           |
+-------------------------------------------+
|                                           |
|  ▼ [訳語案] 未来継承 (支持: 120)            |
|     提案者: @username                     |
|     「可能性」より意志を感じる... (タップで詳細) |
|                                           |
|  ▼ [訳語案] 永続性 (支持: 85)               |
|     提案者: @username2                    |
|     シンプルで使いやすいが... (タップで詳細)     |
|                                           |
|  ▼ [訳語案] ...(以下スクロール)           |
|                                           |
|                                     [+]   | <-- 新しい訳語案の投稿
+-------------------------------------------+
```

  * **タブ切り替え:** この画面の設計が最も重要です。
      * **訳語案一覧 (デフォルト):** 投稿された訳語案を「支持（いいね）」順や新着順で表示します。ユーザーはここで新しい案を投稿します (右下の[+]ボタン)。
      * **議論フォーラム:** この「お題」全体（例: "Sustainability"）に関する自由な議論や、特定の訳語案に対する深い議論を行うスレッドが並びます。
      * **Wikiまとめ:** 議論の成果として、語源、有力な訳語のニュアンスの違い、議論の歴史などが共同編集されます。

-----

### 3\. 訳語案の投稿ページ

**目的:** ユーザーが「2. お題詳細ページ」の[+]ボタンを押した後に表示される、新しい訳語案を投稿するための画面です。

```
+-------------------------------------------+
| [× 閉じる]      訳語案の投稿       [投稿] |
+===========================================+
|                                           |
|  お題: "Sustainability"                   |
|                                           |
| +---------------------------------------+ |
| | あなたの訳語案                          |
| | [ 未来継承                             ] |
| +---------------------------------------+ |
|                                           |
| +---------------------------------------+ |
| | 提案の理由・ニュアンス (任意)           |
| | [ 「可能性」という言葉が持つ...        ] |
| | [                                     ] |
| | [                                     ] |
| +---------------------------------------+ |
|                                           |
|  [🤖 AIによる例文の生成を試す]             |
|                                           |
|  [🤖 AIによる類義語・関連語の提案]         |
|                                           |
+-------------------------------------------+
```

  * **入力欄:** シンプルに「訳語案」と「その理由」を入力できるようにします。
  * **AI補助機能:** 訳語を考える際のヒントとして、また投稿された訳語案がどう使われるかのイメージを掴むために、AIの補助機能をボタンとして配置します。

### 4\. 議論フォーラム（トピック一覧）

**目的:** 「お題詳細」タブの一つ。その「お題」に関する様々な「話題（トピック）」を一覧し、議論の入り口とします。特定の訳語案について深く掘り下げる議論も、お題全体に関する議論もここから始まります。

```
+-------------------------------------------+
| [←戻る]  Sustainability  [☆ブックマーク] |
+===========================================+
|                                           |
|  [ 訳語案一覧 | 議論フォーラム | Wikiまとめ ]  <-- (ここが選択状態)
|                                           |
+-------------------------------------------+
|                                           |
|  [並び替え: 新着順 ▼]  [ ソート: すべて ▼] |
|                                     [+]   | <-- 新しい話題の投稿
+-------------------------------------------+
|                                           |
|  [ トピックカード ]                       |
|  話題: 「未来継承」という訳語案の是非       |
|  <トピック作成者: @username>            |
|  最新: "その視点は..." (3分前 @userB)  |
|                                 [💬 58]   |
+-------------------------------------------+
|                                           |
|  [ トピックカード ]                       |
|  話題: そもそもこの言葉、日本語にする必要ある？ |
|  <トピック作成者: @username2>           |
|  最新: "外来語のままでは..." (1時間前 @userC)|
|                                 [💬 120]  |
+-------------------------------------------+
|  [ トピックカード ] ... (以下スクロール)  |
|                                           |
+-------------------------------------------+
```

  * **設計のポイント:**
      * **タブ:** 「お題詳細ページ」のタブが選択されている状態を示します。
      * **[+]ボタン:** ユーザーが新しい「議論のトピック」を立てるためのボタンです。
      * **トピックカード:** 各議論の「タイトル」と「最新のコメント」を表示し、タップすると「5. 議論詳細（コメント一覧）」画面に遷移します。

-----

### 5\. 議論詳細（コメント一覧）

**目的:** 1つの「トピック」について、時系列でコメントを読み、返信（リプライ）できる画面です。

```
+-------------------------------------------+
| [←戻る] 話題: 「未来継承」の是非...        |
+===========================================+
|                                           |
|  [ トピック本文 (最初の投稿) ]            |
|  投稿者: @username (2日前)                |
|  「未来継承」という案ですが、元の "sustain" |
|  (支える)のニュアンスが... (本文)         |
|                                           |
+-------------------------------------------+
| ▲ 議論のハイライト (AIによる要約) [表示]   |
+-------------------------------------------+
|                                           |
|  [コメント 1] @userB (1日前)              |
|   確かに。ただ「可能性」という言葉では...  |
|   [ ❤️ 5 ]  [ ...返信する ]                |
|                                           |
|      [返信 1-1] @userC (3時間前)         |
|       > @userB さんの意見に賛成です。...   |
|       [ ❤️ 2 ]  [ ...返信する ]            |
|                                           |
|  [コメント 2] @userD (2時間前)              |
|   別の視点ですが...                      |
|   [ ❤️ 10 ] [ ...返信する ]               |
|                                           |
+-------------------------------------------+
| [💬 コメントを入力する...]       [送信]   |
+-------------------------------------------+
```

  * **設計のポイント:**
      * **AIによる要約:** 議論が長くなった場合、AIが「議論の主な論点」を要約し、途中から参加した人へのガイドとします。
      * **スレッド表示:** 返信（リプライ）はインデント（字下げ）され、会話の流れを追いやすくします。
      * **コメント入力欄:** 画面下部に固定し、いつでも議論に参加できるようにします。

-----

### 6\. Wikiまとめ（閲覧）

**目的:** 「お題詳細」タブの一つ。これまでの議論の成果を「まとめ」として共同編集・蓄積する場所です。

```
+-------------------------------------------+
| [←戻る]  Sustainability  [☆ブックマーク] |
+===========================================+
|                                           |
|  [ 訳語案一覧 | 議論フォーラム | Wikiまとめ ]  <-- (ここが選択状態)
|                                           |
+-------------------------------------------+
|                                           |
|  [ ✏️ 編集する ]  [ 🕒 編集履歴 ]             |
|  <最終更新: 5分前 @username3>            |
|                                           |
+-------------------------------------------+
|                                           |
|  ## 概要                                  |
|  Sustainability とは、環境・社会・経済の... |
|                                           |
|  ## 主な訳語案                            |
|                                           |
|  1. **持続可能性** |
|   - 最も広く認知されている訳語。          |
|   - 議論: [「可能性」の是非について(議論#1)] |
|                                           |
|  2. **未来継承** |
|   - このアプリ内で提案された訳語の一つ。    |
|   - 議論: [「未来継承」という訳語案の是非(議論#4)] |
|                                           |
|  ## 議論の歴史                            |
|  - 2025/10/29: @usernameにより「未来継承」が.. |
|  - (以下スクロール)                         |
|                                           |
+-------------------------------------------+
```

  * **設計のポイント:**
      * **編集機能:** 「編集する」ボタンで、「7. Wiki編集」画面に遷移します。
      * **編集履歴:** 誰がいつどこを変更したかを確認できます。
      * **本文:** Markdown形式などで、見出し、箇条書き、リンク（他の議論トピックへの参照など）をサポートし、情報を構造化します。

-----

### 7\. Wiki編集

**目的:** 「6. Wikiまとめ」画面の「編集する」ボタンを押した後の画面です。

```
+-------------------------------------------+
| [キャンセル]       Wikiを編集       [保存] |
+===========================================+
|                                           |
|  [ B ] [ i ] [ H1 ] [ H2 ] [ リスト ] [ リンク ] |
+-------------------------------------------+
|                                           |
|  ## 概要                                  |
|  Sustainability とは、環境・社会・経済の... |
|  (ここにカーソル)                         |
|                                           |
|                                           |
|  ## 主な訳語案                            |
|                                           |
|  1. **持続可能性** |
|   - 最も広く認知されている訳語。          |
|   ...                                     |
|                                           |
|                                           |
+-------------------------------------------+
| [ 変更の概要を入力 (任意) ]               |
+-------------------------------------------+
```

  * **設計のポイント:**
      * **エディタ:** ユーザーがWikiを編集するためのテキストエリアです。
      * **ツールバー:** Markdown記法がわからない人でも簡単に見出しや太字を使えるように補助します。
      * **変更の概要:** 編集履歴に残すため、どのような変更を行ったかを任意で記録できるようにします。

## PC版アプリのワイヤーフレーム案

主な設計思想は「**マルチカラム（多段組み）レイアウトの採用**」です。

### 1\. ホーム画面 (PC版)

**目的:** スマホ版と同様、お題を見つける場所。一覧性を高めます。

```
+--------------------------------------------------------------------------------+
| [アプリロゴ]  [ホーム] [お題を探す]  [新しいお題を提案]   [検索🔍] [👤アイコン]  |
+================================================================================+
|                                                                                |
|  ## 議論が活発なお題                                                           |
|                                                                                |
| +---------------------+  +---------------------+  +---------------------+        |
| | お題: "Sustainability"|  | お題: "Metaverse"     |  | お題: "Agenda"        |        |
| | 代表訳語: 持続可能性  |  | 代表訳語: (なし)      |  | 代表訳語: 協議事項    |        |
| | [💬 58] [案 12]      |  | [💬 120] [案 45]     |  | [💬 30] [案 8]       |        |
| +---------------------+  +---------------------+  +---------------------+        |
|                                                                                |
|  ## 新着のお題                                                                 |
|                                                                                |
| +---------------------+  +---------------------+  +---------------------+        |
| | お題: "Gig Economy"   |  | お題: "Well-being"    |  | ...                   |        |
| | [💬 0] [案 0]        |  | [💬 2] [案 1]        |  |                       |        |
| +---------------------+  +---------------------+  +---------------------+        |
|                                                                                |
+--------------------------------------------------------------------------------+
```

  * **ヘッダー:** スマホ版のフッターナビやボタン類は、すべて画面上部のヘッダーに集約します。
  * **グリッドレイアウト:** スマホ版では縦一列だった「お題カード」を、PC版では横に並べる「グリッドレイアウト（例: 3列）」にし、一度に多くの情報を表示できるようにします。

-----

### 2\. お題詳細ページ (PC版)

**目的:** アプリの核となる画面。スマホ版ではタブで切り替えていた情報を、\*\*2カラム（2段組み）\*\*で効率よく表示します。

```
+--------------------------------------------------------------------------------+
| [アプリロゴ]  (ヘッダーはホームと同じ)                    [検索🔍] [👤アイコン]  |
+================================================================================+
|                                                                                |
| [パンくずリスト: ホーム > お題 > Sustainability ]                              |
|                                                                                |
| +-----------------------------------------------+ +----------------------------+ |
| |                                               | |                            | |
| |  ## Sustainability  [☆ブックマーク]          | | [ お題の基本情報 ]         | |
| |                                               | | 原語の意味・背景           | |
| |  [ 訳語案一覧 | 議論フォーラム | Wikiまとめ ]   | | "sustain (持続する)..."    | |
| |  (ここがメインコンテンツエリア)                 | |                            | |
| | +-------------------------------------------+ | | [ ✏️ Wikiを編集 ]          | |
| | |                                           | |                            | |
| | | ▼ [訳語案] 未来継承 (支持: 120)           | | [ Wikiの目次 (TOC) ]       | |
| | |    提案者: @username                    | |  - 概要                    | |
| | |    「可能性」より意志を感じる...          | |  - 主な訳語案                | |
| | |                                           | |    - 持続可能性            | |
| | | ▼ [訳語案] 永続性 (支持: 85)              | |    - 未来継承            | |
| | |    ...                                  | |  - 議論の歴史                | |
| | |                                           | | (クリックで左側がスクロール) | |
| | | (以下スクロール)                          | |                            | |
| | |                                           | +----------------------------+ |
| | |                                     [+]   | |                            | |
| | +-------------------------------------------+ | | [ 関連する議論トピック ]   | |
| |                                               | |  - 「未来継承」の是非...   | |
| |                                               | |  - 日本語にする必要ある？ | |
| |                                               | +----------------------------+ |
| |                                               | |                            | |
| +-----------------------------------------------+ +----------------------------+ |
+--------------------------------------------------------------------------------+
```

  * **2カラムレイアウト:**
      * **左側 (メインエリア):** スマホ版の「お題詳細ページ」とほぼ同じです。ここでタブ（訳語案/議論/Wiki）を切り替え、メインの作業を行います。
      * **右側 (サイドバー):** お題の基本情報（意味や背景）を常に表示します。さらに、現在選択中のタブに応じて内容が変わります。
          * **「Wikiまとめ」タブ選択時:** 右サイドバーに\*\*Wikiの目次（TOC）\*\*を表示します。クリックすると左側の本文が該当箇所にジャンプします (WikipediaのようなUIです)。
          * **「議論フォーラム」タブ選択時:** 右サイドバーに「活発な議論」「関連する議論」へのショートカットを表示できます。

-----

### 3\. 議論詳細ページ (PC版)

**目的:** 議論の流れを追いやすくします。ここでも2カラムレイアウトが有効です。

```
+--------------------------------------------------------------------------------+
| (ヘッダー)                                                                     |
+================================================================================+
|                                                                                |
| [パンくずリスト: ホーム > お題 > Sustainability > 議論 > 「未来継承」の是非 ]     |
|                                                                                |
| +-----------------------------------------------+ +----------------------------+ |
| |                                               | |                            | |
| |  [コメント 1] @userB (1日前)                  | | [ トピック本文 (固定表示) ]| |
| |   確かに。ただ「可能性」という言葉では...      | | 投稿者: @username          | |
| |   [ ❤️ 5 ]  [ ...返信する ]                    | | 「未来継承」という案ですが...| |
| |                                               | | (議論の元になった投稿)     | |
| |      [返信 1-1] @userC (3時間前)             | |                            | |
| |       > @userB さんの意見に賛成です。...       | | +----------------------------+ |
| |       [ ❤️ 2 ]  [ ...返信する ]                | |                            | |
| |                                               | | [ 🤖 AIによる議論の要約 ]  | |
| |  [コメント 2] @userD (2時間前)                  | |  - 論点1: ...              | |
| |   別の視点ですが...                          | |  - 論点2: ...              | |
| |   [ ❤️ 10 ] [ ...返信する ]                   | |                            | |
| |  (以下スクロール)                             | |                            | |
| |                                               | +----------------------------+ |
| |                                               | |                            | |
| | +-------------------------------------------+ | |                            | |
| | | [💬 コメントを入力する...]       [送信]   | | |                            | |
| | +-------------------------------------------+ | |                            | |
| |                                               | |                            | |
| +-----------------------------------------------+ +----------------------------+ |
+--------------------------------------------------------------------------------+
```

  * **2カラムレイアウト:**
      * **左側 (メインエリア):** コメントのスレッドが時系列で表示されます。スクロールしても右側は固定されます。
      * **右側 (サイドバー):** 議論の発端となった「トピック本文（最初の投稿）」や「AIによる議論の要約」を常に表示しておくことで、議論が横道にそれても、本来のテーマを忘れないように補助します。
